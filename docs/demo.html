デモ用バーコード

App Review - コナモンのバーコードスキャン機能をテストするためのデモ用バーコードです

テスト手順

  1. このページを別のデバイス（PCまたは別のiPad/iPhone）に表示します
  2. コナモンアプリを起動し、カメラ画面を開きます
  3. 下記のバーコードのいずれかにカメラを向けます
  4. バーコードが認識されると、薬品名が自動表示されます
  5. 「撮影する」をタップして秤量写真を撮影します
  6. 印刷ボタンから記録を印刷できます（AirPrint対応プリンターが必要）
